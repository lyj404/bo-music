# Inno Setup Simplified Chinese translation

`ChineseSimplified.isl` is vendored unchanged from the official Inno Setup
repository at commit `97c4aa92235f44d0ee6617d739eb9ab0bdb404bf`:

https://github.com/jrsoftware/issrc/blob/97c4aa92235f44d0ee6617d739eb9ab0bdb404bf/Files/Languages/ChineseSimplified.isl

It targets Inno Setup 6.5.0 or newer. The upstream license is preserved in
`InnoSetup-LICENSE.txt`; translation maintainer credits remain in the language file.

The installer uses this repository copy so packaging does not depend on which
translations are bundled with the compiler installed locally or on CI runners.
When updating, pin the upstream commit, preserve the original file and license,
and compile the installer to check compatibility.
